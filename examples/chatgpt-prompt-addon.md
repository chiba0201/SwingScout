# ChatGPT に渡す指示文（追記分）

市況メモを作ってもらうときの指示文の**最後に、下の枠内をそのまま追記**してください。
メモ本文はこれまでどおり自由な文章でかまいません。最後に付く「SwingScout用まとめ」を、Today 画面が決まった形で読み取ります。

- 毎朝**同じ ChatGPT の会話（またはプロジェクト）で続けて**メモを作ると、前日までのメモを踏まえた「今週」の見通しになります。

- 書式を変えるときは、読み取り側（`src/lib/memoBrief.ts`）も合わせて直してください。
- まとめが無いメモでも Today には反映できます（本文から読める範囲だけになります）。

---

```text
## 最後に「SwingScout用まとめ」を付けてください

メモ本文のあとに、次の形式のまとめを必ず付けてください。アプリが機械的に読み取るので、書式を守ってください。

- まとめ全体を1つのコードブロック（```）に入れる
- 1行目は【SwingScout】、最後の行は【SwingScout ここまで】
- 1行に1項目。「項目名：内容」の形（項目名は下の例のとおり。コロンは全角「：」）
- 確認できなかった値は書かない（推測で埋めない）。確認できなかった指標・項目は「未確認」の行に書く（今日の判断に影響するものだけ、多くても5件）
- 同じ指標を複数行書くとき（大取とCMEの先物など）は、判断に使う方を先に書く
- 銘柄には必ず証券コードを半角かっこで付ける（例：フジクラ(5803)、キオクシア(285A)）。複数は「、」区切り
- 数値は半角。前日比は「+0.49%」「-3.44%」のように符号と%を付ける（金利は「-4.0bp」でもよい）
- 節目・指標・関連株・PTS・材料・イベントは、1行に1件で何行でも書いてよい。行の中は「｜」で区切る
- 該当がない項目は行ごと省く
- 「今週」は今日の結論の言い換えにしない。この会話で前日までに作った市況メモの流れ（スタンス・本線・セクターの変化）と、保有期間中のイベント（SQ・FOMC・決算など）を踏まえて、数日先の見通しを書く

【SwingScout】
対象日：YYYY-MM-DD
確認時刻：HH:MM
区分：寄り前（寄り前／前場／昼休み／後場／引け後 のどれか）
結論：今日の方針を1文で（60字以内）
今週：次の保有期間（火曜IN〜金曜OUT）にかけての見通しを1〜2文で（今日の寄り付きの話は書かない）
スタンス：買い目線／押し目待ち／様子見／リスクオフ のどれか1つ
想定寄り：ややGU +0.3%（大幅GU／ややGU／横ばい／GD のどれかと、日経平均の前日終値比の目安）
寄り付き：71532 +1.20%（寄った後のメモだけ。日経平均の実際の始値と前日終値比。寄る前のメモでは書かない）
サイズ：通常サイズ／理由を短く
本線：今日いちばん狙う銘柄(コード)、銘柄(コード)
確認後：強さを確認できたら候補にする銘柄(コード)
待機：様子を見る銘柄(コード)
避ける：今日は触らない銘柄(コード)
優先：優先して監視するセクター
選別：銘柄を選んで扱うセクター
慎重：慎重に扱うセクター
入る条件：エントリーの条件を1〜2文で
撤回条件：今日の本線をやめる条件（反証）を1〜2文で
損切り：損切りの決め方を1文で
節目：70798.62｜昨日高値（日経平均の現物の節目。高い順に3〜6行）
指標：名前｜値｜前日比｜補足（日経平均・TOPIX・日経先物・ダウ・S&P500・NASDAQ・SOX・VIX・日経VI・ドル円・米10年金利・日本10年金利・WTI のうち確認できたもの。補足は「4:28時点」「CME」など）
関連株：分野｜銘柄｜前日比（米国の関連株。例：光通信｜Lumentum｜+3.82%）
PTS：銘柄(コード)｜価格｜東証終値比
材料：銘柄(コード)｜内容を1文で｜好材料／悪材料／中立
イベント：HH:MM｜内容｜高／中／低（翌日以降は「M/D HH:MM」）
広がり：値上がり・値下がり銘柄数や売買代金などを1文で
未確認：今日の判断に影響する未確認の項目（多くても5件）
【SwingScout ここまで】
```
